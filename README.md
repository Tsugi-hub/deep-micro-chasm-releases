# Deep Micro-Chasm — Ruptura Studios

Downloads oficiais para Windows e Android.

- [Baixar a versão mais recente](https://github.com/Tsugi-hub/deep-micro-chasm-releases/releases/latest)
- [Todas as versões e notas de atualização](https://github.com/Tsugi-hub/deep-micro-chasm-releases/releases)

No PC, baixe o arquivo Windows-Setup.exe. No celular, baixe Android.apk e confirme a instalação pelo Android. Atualize sem desinstalar a edição anterior nem apagar os dados do aplicativo.

A partir da versão 0.7.0, o correio do jogo consulta este canal automaticamente. No Windows, a atualização verifica a assinatura do instalador e salva a partida antes de instalar. No Android, abre o APK oficial para confirmação pelo sistema. A consulta e os downloads exigem internet; a partida funciona offline.

O código-fonte é privado. Este repositório guarda somente instaladores, APKs, checksums, manifestos e notas. Os arquivos Source code gerados automaticamente pelo GitHub contêm apenas a documentação deste repositório.

Saves e preferências ficam no aparelho do jogador. Não são enviados ao GitHub e não são sincronizados entre PC e celular. Exporte backups pelo menu de pausa. Guarde seus backups antes de desinstalar ou apagar dados.
